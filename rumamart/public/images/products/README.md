# Foto produk RumaMart

Taruh foto produk (format .jpg) di folder ini dengan nama file yang sama seperti
field `image` di `src/data/products.js`, contohnya:

- `rak-piring-stainless.jpg`
- `set-pisau-dapur.jpg`
- `wajan-anti-lengket.jpg`
- ... (lihat daftar lengkap di `src/data/products.js`)

Rekomendasi: rasio persegi (1:1), minimal 600 x 600 px.

Selama sebuah foto belum ada, kartu produk otomatis menampilkan ilustrasi emoji
sebagai pengganti, jadi tampilan tidak pernah rusak. Kamu juga boleh mengganti
nilai `image` dengan URL gambar eksternal yang valid.
